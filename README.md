# Northwind Data Platform

Migrating a traditional Microsoft BI stack to a modern, container-based
data engineering platform.

## Architecture

    OP (SQL Server) → Staging (PostgreSQL) → DW (ClickHouse) → Grafana
                    orchestrated by Apache Airflow

## Stack

Docker · Apache Airflow · Apache Spark · ClickHouse · PostgreSQL ·
SQL Server · Grafana
